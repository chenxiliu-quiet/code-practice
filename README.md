# code-practice

大一的编程练习与学习笔记，持续更新。

## 目录结构

| 目录 | 内容 |
| --- | --- |
| `java/pi-exercises/` | 圆周率相关的 Java 练习题：格式化输出、精度比较、误差分析等 |
| `python/docx-layout/` | 用 Python 把 Word 文档自动重排成一页一题的小工具 |
| `docs/` | 自己整理的学习路径与周计划（HTML，用浏览器直接打开） |

## 说明

- **Java**：在校课程练习，代码保持练习时的原样，主要记录思路演变。
- **Python**：为某个具体 docx 写的排版脚本，里面的文件路径需要按自己的环境改。
- **docs**：学习路线整理，不是代码，可以随意参考。

## 环境

- Java：JDK 17+（`javac XX.java && java XX`）
- Python：3.8+，排版脚本需要 `python-docx`
