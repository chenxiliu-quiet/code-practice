游戏开发四年学习路径

米哈游（miHoYo）定向优化版 · 大一 → 大四

零、先回答最关键的问题：必须学 C++ 吗？

结论：C# 是主力武器，C++ 是必修功底。两者都要，但角色不同——不要把 C++ 当成主攻方向，也不要以为会 C# 就够了。
问题答案
米哈游主力技术栈是什么？ Unity + C#。《原神》《崩坏3》《崩坏：星穹铁道》均为 Unity 开发，日常业务代码写 C#。
那还需要 C++ 吗？ 需要，且是硬门槛。三个原因：① 校招笔试 / 技术面八股普遍以 C++ 为通用语言；② 引擎、图形学、TA 岗必须精通 C++；③ 性能优化与底层理解绕不开它。
学习优先级怎么排？ C# 先深（对接 Unity、快速出作品）→ C++ 补底层（对接面试、引擎、图形学）。顺序可以交叉，但主线是 C# + Unity。
只学 C++ 能进米哈游吗？ 能，但只对引擎 / 图形学 / 服务器方向成立，且这些岗竞争最激烈、学历要求最高（多为硕士）。游戏客户端岗仍需 Unity + C# 项目经验。

二、优化后的四年路径

大一：基础建立 + 最快出作品

时间任务
9–10 月保留C 语言速通（变量/函数/数组/指针，控制在 1–1.5 个月）——它是 C++ 的地基，也打计算机基础。同时熟悉 Visual Studio、Git。
11–12 月C# 深入（面向对象/类/继承/多态/集合/委托）+ Unity 起步。C# 是你未来四年的主武器，不要浅尝辄止。
寒假第一个可玩的 Unity 游戏 Demo（打地鼠 / 飞机大战级别）。这是建立正反馈的关键里程碑。
下学期Unity 深入（角色控制 / UI / 动画 / 物理）+ 数据结构基础 + 开始刷题（LeetCode easy，每周 3 题）+ 新增接触竞赛（蓝桥杯 / CSP 入门）+ 发布第一个游戏视频。
暑假完成一个完整小游戏 + 运营账号 + 提前开始接触 C++（语法 + 编译链接 + 指针复习）。

大二：C++ 补强 + 算法 + 项目（最容易拉开差距的一年）

板块任务
C++ 系统学习提前语言特性 / 面向对象 / STL / 内存管理 / 智能指针 / 移动语义。目标：能独立写出结构清晰的 C++ 程序。
算法刷题强化LeetCode 累计 200 题（easy/medium 为主），保持每周 3–5 题。这是米哈游笔试的敲门砖。
Unity 进阶性能优化、对象池、热更新、网络同步基础、编辑器工具。做一个 3D 项目。
数学强化线性代数（向量/矩阵/变换）、微积分。不只为考试——这是图形学的地基。
计算机基础
四大件		新增操作系统 + 计算机网络 + 计算机组成原理（数据结构大一下已开始）。这是校招面试八股的核心，详见第三节。
项目2D + 3D 各一个，学习游戏系统设计（战斗 / 背包 / 存档 / 任务）。
UP 主提升 PR/AE，学习脚本、选题、内容策划，保持稳定更新。

大三：方向聚焦 + 实习冲刺（决定性一年）

时间任务
大三上
  • 确定主方向（客户端 / 引擎 / TA / 服务器），停止平均用力
  • 图形学：GAMES101（计算机图形学入门）系统过完；如走引擎/TA，继续 GAMES202 / 《Real-Time Rendering》
  • 刷题冲刺：累计 300 题以上，开始接触 medium-hard
  • 旗舰项目启动：一个拿得出手的完整作品（详见第四节）
大三下
（3–5 月）		 关键修正投递米哈游暑期实习——这是进入米哈游最重要的通道，很多 offer 由实习转正产生。不是大四才准备实习！同时可投腾讯/网易/其他游戏公司作为练手。
大三暑假实习（争取大厂）。实习期间积累真实项目经验，这是秋招简历上最重的一笔。

大四：秋招收割

时间任务
7–8 月米哈游秋招提前批（一般 7–8 月启动，越早投越好）+ 其它大厂提前批。
9–11 月正式批：网申 → 笔试（算法）→ 技术面（C++/C#、操作系统、计网、数据结构、图形学、项目）→ HR 面。
贯穿作品集打磨（重点讲旗舰项目）、八股复盘、面试模拟。
备选若学历需要补强或不理想：考研（计算机/图形学方向），次年再战。

三、计算机基础四大件（必须补上）

⚠️ 这是原先路径最大的缺口。无论走游戏客户端、引擎还是考研，数据结构 / 操作系统 / 计算机网络 / 计算机组成原理都是校招面试的必答题——不会这些，笔试过了面试也会挂。
科目为什么重要学什么推荐资源 / 时间
数据结构 一切的地基；面试必考；算法刷题的前提 线性表、栈与队列、树、图、排序、查找、哈希 陈越《数据结构》MOOC（浙大）/ 王道
大一下 – 大二
操作系统 面试八股核心；引擎底层（内存 / 多线程）必备 进程与线程、内存管理、文件系统、并发同步、死锁 王道考研操作系统 / CSAPP
大二
计算机网络 面试八股核心；联机游戏、网络同步的基础 TCP/IP、HTTP、网络分层、三次握手四次挥手、拥塞控制 王道 / 谢希仁《计算机网络》
大二
计算机
组成原理		 理解硬件与性能；做引擎 / 优化时的底层认知 CPU、指令系统、存储层次（缓存）、流水线、总线 王道 / CSAPP（深入理解计算机系统）
大二 – 大三
学习原则：这四门不要只背八股，要动手写代码复现（如手写线程池、实现简易 HTTP 服务器、模拟内存分配）。面试官最反感"只会背"的人。

四、竞赛（加分项，性价比高）

竞赛类型难度建议
蓝桥杯个人低 – 中 大一就能参加，门槛最低，最适合起步。省一 / 国奖对简历有实在加分。
CSP（CCF）个人中 – 高 CCF 认证，含金量中上，成绩可写入简历，部分大厂岗位认可。
ACM / ICPC团队高 含金量最高，但需进校队、投入巨大。有区域赛奖牌 = 算法能力的硬证明。
天梯赛团队中 PAT 系列团队赛，适合有校队资源时参与。
刷题平台：LeetCode（面试向，主力）+ 洛谷（竞赛向，配合蓝桥杯 / CSP）。
优先级提醒：四大件 > 竞赛。竞赛是加分项，四大件是必答题。时间冲突时，先把四大件学扎实。

五、相对原始规划，改了什么（以及为什么）

改动原规划原因
提前C++ 学习时间 大二开始 米哈游笔试与技术面普遍考 C++，早接触能更早参与真实项目与刷题；大一暑假先打底，大二系统学。
强化算法刷题 仅"学习算法" 米哈游笔试算法难度高。刷题量是硬指标：大二 200 题 → 大三 300+ 题，没有它连面试都进不去。
加强图形学与数学 大三提了一句"Shader、优化" 米哈游引擎/TA 岗的命脉。线代 + 图形学（GAMES101 等）必须系统学，不能只当口号。
修正实习时间线 大四才"准备实习" 这是原规划最大的硬伤。大三下（3–5 月）就要投暑期实习，那是主要留用通道；大四才准备已经错过关键一战。
明确旗舰项目要求 3–5 个完整作品 数量不如深度。面试官只看那一个"能打"的项目：完整系统 + 性能优化 + 真实玩家。
补充学历路径决策 未提及 米哈游对学历敏感，需在大二结束前决定"校招硬冲"还是"考研补学历"。
补齐计算机基础四大件 仅提"数据结构、数据库、计网" 原规划缺 操作系统 和 计算机组成原理，且没有系统的时间安排。这四门是校招面试的必答题，必须补齐。
新增竞赛 完全未提 算法竞赛是算法能力的硬证明，也是简历筛选的加分项。蓝桥杯门槛低、大一即可参加，性价比最高。
保留四年递进框架与 UP 主线 — 原规划的整体节奏、技能优先级、UP 主运营和"持续产出作品"的理念是对的，保留。

六、什么算"能打"的旗舰项目

大四面试时，这一个项目比另外四个 demo 都重要。它至少要包含：

  • 完整玩法闭环：开始 → 游玩 → 胜负/结算 → 重开，不是零散的功能演示
  • 完整系统：至少 3 个（如战斗 / 背包 / 存档 / 任务 / UI / 音效）
  • 性能优化痕迹：对象池、批处理、Profiler 调优数据（面试官很吃这一套）
  • 真实发布：上架 itch.io / Steam，有玩家下载和反馈
  • 能讲清楚：架构怎么设计、遇到过什么坑、怎么解决的——这决定面试成败

八、核心理念

① C# 主攻，C++ 必修——主武器和功底，别搞反。
② 基础是入场券——四大件（数据结构 / 操作系统 / 计网 / 组成原理）不过关，笔试过了面试也会挂。
③ 深度 > 广度——大三必须收敛到一个方向，什么都学一点的人最容易被淘汰。
④ 作品 + 实习 + 竞赛 > 学历——学历是门槛，作品、实习与竞赛是决定性的那一票。
⑤ 不要只学习工具，要持续产出作品——这是原规划里最好的一句话，保留。
